# ml/experiments

One directory per experiment: `EXP-NNN-short-name/` containing `README.md` (objective, hypothesis,
data, exact commands, environment, git commit, results, conclusion), scripts, configs and small
result files (CSV/JSON). Never commit audio or checkpoints. Summarise conclusions in
`docs/agent/FINDINGS.md` and quantitative results in `docs/MODEL_EVALUATION.md`.
