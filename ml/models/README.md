# ml/models

Model checkpoints are **downloaded, never committed** (git-ignored). For each model add a
`<model-name>.md` here with: source URL, exact file names, SHA-256 checksums, license of code and
weights, download command, and the `ModelInfo` values (sample rate, embedding dim, preprocessing)
the provider reports. No model has been selected yet (docs/MODEL_RESEARCH.md).
